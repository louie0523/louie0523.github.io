GitHub로 연결 추천

어디서든 편집하고 [게시]를 누르면 저장소에 바로 커밋됩니다. 토큰은 이 브라우저에만 저장됩니다.

토큰 만드는 법 (1분)
  1. GitHub → Fine-grained token 만들기 열기
  2. Repository access: Only select repositories → 포트폴리오 저장소 하나만 선택
  3. Permissions → Repository → Contents: Read and write
  4. 생성된 github_pat_…를 위 칸에 붙여넣기

이 토큰은 그 저장소 하나만 수정할 수 있습니다. 토큰이 없으면 이 페이지를 누가 열어도 아무것도 저장할 수 없습니다.

내 컴퓨터 폴더로 열기

저장소를 클론해 둔 폴더를 직접 수정합니다. 커밋/푸시는 GitHub Desktop 등으로 직접 하세요. (Chrome · Edge 전용)
